mlir实践之方言定义

发表于2025-11-07|更新于2026-03-25|编译器/mlir
|浏览量:

从本篇文章开始，详细介绍方言的开发记录，包括该怎么做，为什么这么做之类的。
本节首先介绍北极星方言的定义，包括NorthStarDialect.td文件，通过mlir-tablegen工具生成的NorthStarDialect.h.inc文件和NorthStarDialect.cpp.inc文件，以及NorthStarDialect.h文件以及NorthStarDialect.cpp文件。
在这里需要注意这4个文件之间的关系。可以这么理解，inc文件是整个文件的部分切片文件，只是保存了一些最基础的声明与定义，但是具体的实现是在对应的.h/.cpp文件中。

当前项目的目录结构

在当前目录中，最重要的是这里的不同层次的CMakeLists.txt文件内容、NorthStarDialect.td文件内容以及NorthStarDialect.h/.cpp文件，main.cpp文件只是实现了方言的注册以及调用其中的方法。

顶层 CMakeLists.txt 文件

在这个 CMakeLists.txt 文件中，主要进行一些基础设置，比如说 cmake 版本号、项目名。其中最重要的设置与llvm/mlir相关的东西，首先通过find_package(MLIR REQUIRED CONFIG)命令配置一些基础的变量，比如说LLVM_CMAKE_DIR、MLIR_CMAKE_DIR等，然后通过list命令添加llvm/mlir的相关模块。最后，由于当前文件位于整个项目的最顶层，所以要添加一些包含CMakeLists.txt文件的子目录，方便构建整个项目。当然为了测试，需要构建最终的可执行文件，这个可执行文件依赖于北极星方言生成的库文件，命令如下：target_link_libraries(northstar NorthStarDialect)，在这里，NorthStarDialect就是北极星方言生成的库文件。具体的 CMakeLists.txt 文件内容如下：

include目录

这个目录下主要放的是各种.td文件以及头文件定义，类似于方言的td文件、方言操作的td文件、方言属性的td文件以及对应的头文件都会放在这里。

include/CMakeLists.txt 文件

这个文件主要是为了包含保存CMakeLists.txt文件的目录，用于添加这些目录，方便后续查找。

include/NorthStar/CMakeLists.txt 文件

在这个文件中，一般是基于.td文件，使用tablegen工具（在cmake中使用mlir-tablegen工具生成对应的inc文件），并且构建方言的库文件。在这里，可以创建一个接口库，这个接口库不编译实际代码，只传递属性，可以通过这个接口设置头文件的搜索路径，比如说这个项目的include路径（包含这个项目自定义的一些头文件，变量名为CMAKE_CURRENT_SOURCE_DIR）、这个项目生成的build下的头文件（比如说inc文件，变量名为CMAKE_CURRENT_BINARY_DIR）、以及mlir源项目中的头文件路径（即mlir自带的头文件，变量名为MLIR_INCLUDE_DIRS）。最后通过add_dependencies(NorthStarHeaders MLIRNorthStarDialectIncGen)设置依赖关系链，如何理解这里的依赖关系链呢？可以这么理解，你要编译最终的可执行文件，但这个可执行文件可能依赖某个库文件，所以需要先编译出这个库文件，然后才能构建最终的可执行文件。

上述CMakeLists.txt文件有如下关系：

  • MLIRNorthStarDialectIncGen —— TableGen 生成目标
    这是一个 TableGen 自动生成目标（target），不是库。它的作用是：让 CMake 知道，执行 ninja MLIRNorthStarDialectIncGen 时，会调用 mlir-tblgen 工具，根据 .td 文件生成 .inc 文件。
  • NorthStarDialect.h.inc / NorthStarDialect.cpp.inc —— 生成的文件
    它们是 TableGen 输出文件，通常分别包含：
    • NorthStarDialect.h.inc → dialect 声明部分（类声明、注册接口）
    • NorthStarDialect.cpp.inc → dialect 定义部分（构造函数注册、op注册表）
  • NorthStarHeaders —— INTERFACE 接口库
    INTERFACE 目标是一种 逻辑 target，不会生成 .a 或 .so 文件，它只用于在 CMake 中 传递属性（include 路径、依赖关系等）。在这里，NorthStarHeaders 中保存的是所有的头文件路径。

在这里，有以下几点需要注意：

  • NorthStarDialect是cmake 的target的名字，在构建后，可以使用target_link_libraries(<exe> NorthStarDialect) 把该方言库链接进可执行文件或测试用例。
  • 源文件列表 NorthStarDialect.cpp：列出构建该库所需的源文件。通常是实现方言初始化、op 注册、接口实现等的 .cpp 文件。如果有多个 .cpp，可以一并列出。
  • ADDITIONAL_HEADER_DIRS：这个关键字用于告诉 add_mlir_dialect_library，在编译该 target 时额外需要把哪些目录加入到 include 搜索路径。
  • DEPENDS MLIRNorthStarDialectIncGen：这个 DEPENDS 与 add_mlir_dialect_library 结合使用，告诉 CMake：在编译该库之前必须先生成某个目标（通常是 TableGen 生成的文件）
  • LINK_LIBS PUBLIC ...：列出该库需要链接的其他库（可以是 MLIR core 库、其他方言库或你的 INTERFACE 头库）
