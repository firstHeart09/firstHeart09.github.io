mlir实践之mlir目录组织方式

发表于2025-11-01|更新于2026-03-25|编译器/mlir
|浏览量:

本章节开始，主要是介绍 mlir 项目的推荐目录组织形式以及每一层目录的CMakeLists.txt文件到底做了什么，方便后续在实际开发中理解并应用。

项目目录结构介绍

以北极星方言为例，介绍整个方言的目录组织结构，如下：

对应的每层的 CMakeLists.txt 文件内容

顶层 CMakeLists.txt 文件内容

在顶层 CMakeLists.txt 文件中，一般会声明此项目使用的 cmake 版本以及项目名，同时在该文件中也会配置对应的mlir/llvm路径，然后会将类似的AddMLIR.cmake文件添加到路径中，方便在子CMakeLists.txt文件中使用。同时在该文件中，也会包含各种头文件，比如说mlir的头文件等等，然后包含子目录（子目录中包含CMakeLists.txt文件）。
一般来讲，该文件的内容如下：

include 层

include 目录负责放置 .td 与公开头；同时负责调用 mlir_tablegen 生成 .inc 文件并创建 tablegen 目标（add_public_tablegen_target），供后续库依赖。

include/CMakeLists.txt文件

在该文件中，一般只会包含子目录，不会进行其他操作，如下：

include/NorthStar/CMakeLists.txt

在这个文件中，一般会利用 mlir-tablegen 工具，针对 .td 文件生成对应的 .inc 文件，在这点有4个要点：

  • 每次调用 mlir_tablegen 前 set(LLVM_TARGET_DEFINITIONS <file.td>)
  • 生成的 .inc 文件应该输出到 ${CMAKE_CURRENT_BINARY_DIR}（默认 mlir_tablegen 会生成到 binary dir）
  • 使用 add_public_tablegen_target(<Name>) 创建公共 tablegen 目标，供 lib 依赖 DEPENDS。
  • 把生成目录（binary include）添加到 PUBLIC include dirs，保证其他 targets 能 #include 这些生成头。

lib 层

lib 包含 IR、Transforms、Conversion 三个子目录。lib/CMakeLists.txt 仅添加子目录。

lib/CMakeLists.txt

在该文件中，一般只会增加子目录，如下：

lib/IR/CMakeLists.txt—-方言实现库

定义方言 IR 层的库。

lib/Transforms/CMakeLists.txt

实现优化 Pass

如果你定义了 Pass（在 .td 文件中），就需要：

lib/Conversion/CMakeLists.txt
