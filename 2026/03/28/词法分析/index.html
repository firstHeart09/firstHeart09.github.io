编译器中间表示
在整个编译流程中，存在多种中间表示。如GCC编译器的中间表示可以有以下几个阶段：GENERIC、GIMPLE、Tree SSA和RTL；在llvm中存在llvm IR，需要注意的是，在llvm IR中，每一个寄存器（变量）一旦被赋值，就不能再次被赋值，这就是静态单赋值最核心的要点。 举例说明假设有如下C语言代码： 12x = 1;x = x + 1; // x 被修改了 对应的SSA中间表示如下： IR12x_1 = 1;x_2 = x_1 + 1; SSA又叫静态单赋值，其核心思想是：给每一次赋值产生一个新的变量版本，使得每一个版本只定义一次。 此时，每一个use使用都能明确对应到某一个定义上，数据流关系很清楚。为了能够明确这个数据流，在这里会使用φ函数节点，完成这个处理。φ函数节点可以理解成：控制流汇合处的值选择器，该节点不是运行时真的去调用某个函数，而是让编译器在IR里面表达： 如果程序从某个前驱块中走过来的，就选择那个前驱块里对应版本的值。 φ不是机器指令，而是IR层的伪操作，它的主要作用是让SSA在分支合流和循环回边处仍然成立，同时让常量传播、死代码消除和值范围分析这...
